# Contributing to html to pdf

Thank you for your interest in improving this project. Contributions from the community help make this tool more reliable and efficient for everyone.

## How to help

* **Report bugs** through GitHub Issues. Include clear steps to reproduce the problem and any relevant error logs.
* **Suggest features** or major changes in the Discussions tab before starting work to ensure they align with the project goals.
* **Submit pull requests** for bug fixes, performance improvements, or documentation updates.

## Local setup

Ensure you have Node.js installed on your system.

1. Fork the repository on GitHub.
2. Clone your fork to your local environment.
3. Run `npm install` to install all necessary dependencies.

## Coding standards

We use Javascript for all development in this repository. Keep your code simple, direct, and well commented where logic is complex. Avoid adding unnecessary dependencies or complex abstractions. Follow the existing patterns in the codebase to maintain consistency across the project.

## Pull request guidelines

* Create a specific branch for every separate fix or feature.
* Write concise commit messages that clearly describe the change.
* Test your changes thoroughly to ensure they do not break existing functionality.
* Provide a brief summary in your pull request explaining what was changed and why it is necessary.

## Discussions and questions

If you have questions about how to use the tool or want to brainstorm new ideas, please use the **Discussions** section. We aim to keep the **Issues** section strictly for actionable tasks and confirmed bugs.

We look forward to your contributions and appreciate your help in building this community.
