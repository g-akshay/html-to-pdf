# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please do not disclose it publicly through GitHub issues or discussions. Private reporting allows us to fix the issue before it can be exploited.

Please send a detailed report to the maintainer via the contact information provided on the GitHub profile. Include the following details in your report:

* A clear description of the vulnerability.
* Steps to reproduce the issue, including any relevant Javascript code snippets.
* The potential impact on users or systems.
* Any proposed fixes or workarounds you have identified.

## Non Security Issues

For general bugs, feature requests, or questions about how to use the tool, please use the Issues or Discussions tabs. This security policy is strictly for reporting flaws that could compromise the safety or integrity of the software and its users.
